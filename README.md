# StockFlow — Inventory & Procurement Management System

StockFlow is a full-stack inventory and procurement management application designed to help teams track products, warehouse stock, suppliers, purchase requests, purchase orders, goods receipts, and stock movement with clear role-based workflows.

## Planned technology
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Java, Spring Boot, Spring Security
- Database: PostgreSQL
- API: REST with OpenAPI documentation
- Testing: JUnit, Mockito, integration tests
- Delivery: Docker and GitHub Actions

## Core capabilities
- Product and SKU catalogue
- Multiple warehouses and stock transfers
- Stock adjustments and low-stock alerts
- Supplier directory
- Purchase requests, approvals, and purchase orders
- Goods receiving and inventory reconciliation
- Role-based access for administrators, procurement officers, warehouse managers, employees, and auditors
- Audit history and operational reports

## Project status
Initial repository setup. Features will be implemented incrementally with tests and documented setup instructions.

## Development
The repository will contain separate frontend and backend applications, database migrations, API documentation, automated tests, and containerized local development.
